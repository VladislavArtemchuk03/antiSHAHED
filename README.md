# AntiSHAHED

Інтерактивна карта повітряних тривог України. Дані надходять з [alerts.in.ua](https://devs.alerts.in.ua/) через серверний проксі, тому токен не передається у браузер. Без токена карта використовує публічний live-звіт сервісу; з токеном застосовується структурований JSON API.

## Налаштування API

1. Отримайте токен на [alerts.in.ua/api-request](https://alerts.in.ua/api-request).
2. Створіть `.env` на основі `.env.example`.
3. Укажіть значення `ALERTS_IN_UA_TOKEN`.

```env
ALERTS_IN_UA_TOKEN=your-token
```

Не додавайте `.env` до Git.

## Запуск

```bash
npm install
npm run dev
```

Для production-запуску створіть збірку й запустіть серверний проксі:

```bash
npm run build
npm start
```

Карта оновлює дані щохвилини. Стани регіонів визначаються API: зелений - немає активної події, жовтий - попередження або жовтий рівень, червоний - червоний рівень чи критичні типи загроз (обстріл, бої, хімічна або радіаційна загроза).

## GitHub Pages

Workflow автоматично збирає та публікує сайт на GitHub Pages після змін у `main`, а також оновлює статичний публічний звіт тривог кожні 5 хвилин. Для першої публікації в налаштуваннях репозиторію відкрийте **Settings → Pages** і виберіть **GitHub Actions** як джерело розгортання. На Pages показуються дані з останнього успішного запуску workflow; локальний запуск і надалі використовує серверний проксі.
